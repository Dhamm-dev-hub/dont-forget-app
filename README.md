# Drishti AI 👁️

Drishti AI is an AI-powered visual assistant designed to help blind and visually impaired users understand their surroundings.

## Features

- 📷 Live camera access
- 🤖 AI scene description
- 👗 Outfit and clothing description
- 📝 Text reading (OCR)
- 🔍 Object finding
- 🗣️ Hindi voice output
- 🎙️ Voice commands
- 💬 Ask questions about what the camera sees
- 🔄 Front and rear camera switching
- ♿ Accessible interface

## Technology

- HTML
- CSS
- JavaScript
- Node.js
- Express
- OpenAI API

## Setup

1. Clone the repository.
2. Install dependencies:

   npm install

3. Set your OpenAI API key as an environment variable:

   OPENAI_API_KEY=your_api_key

4. Start the application:

   npm start

5. Open the app in your browser.

## Safety

Drishti AI is an assistive tool. AI descriptions may be inaccurate. Never rely on it alone for road crossing, navigation, identifying dangerous objects, or other safety-critical decisions.
